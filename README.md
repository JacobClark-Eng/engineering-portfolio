## Preview locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge, or another browser.
3. Use the navigation and project cards to browse the site.

## Publish with GitHub Pages
1. Create a GitHub repository for the portfolio.
2. Upload the **contents** of this folder to the repository root (including `index.html`, `style.css`, `assets/`, and `projects/`).
3. Under repository Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`.
4. Wait for GitHub Pages to publish, then test each link and image.
